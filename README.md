# 📈 TradeX

An AI-powered stock trading platform built with the MERN Stack. TradeX enables users to manage portfolios, monitor markets, create watchlists, place orders, and gain AI-driven investment insights through a secure and modern web application.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/TradeX.git
```

---

### Backend

```bash
cd Backend
npm install
npm run dev
```

---

### Frontend

```bash
cd Frontend
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file inside Backend.

```env
PORT=

MONGODB_URI=

ACCESS_TOKEN_SECRET=

REFRESH_TOKEN_SECRET=

EMAIL_USER=

EMAIL_PASS=

GEMINI_API_KEY=

RAZORPAY_KEY_ID=

RAZORPAY_KEY_SECRET=
```
